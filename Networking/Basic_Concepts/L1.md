# Network Devices

 |_ Hosts - A device that send or receives traffic, Ex. (Printer, Laptop, Mobile, Servers, Clouds Servers, IoT devices).
 |_ Client - Initiates a request 
 |_ Server - Server responds to the request (Serves the request).
 |_ IP (Internet Protocol) - Identity of each host. 32 bits (0 or 1)
 |_ Network - Logical grouping of hosts which require similar connectivity, it also contains other networks (sub-network/subnets).
 |_ Repeater - It regenerates signals.
 |_ Hub - Multi-port repeaters.
 |_ Bridge - It sits between Hub-connected hosts.
 |_ Switches -  Facilitate communication within a network.
